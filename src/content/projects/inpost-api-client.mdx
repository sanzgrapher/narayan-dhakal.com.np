Inpost is a **Postman / Insomnia-style** desktop client built for humans and AI agents. Build requests with params, headers, body and auth; organise them in collections; switch environments with `{{vars}}` (secrets stay on this device). The response pane docks to the right or bottom with status, timing and JSON.

A status bar shows **Inpost MCP** listening locally, so agents can call endpoints, manage collections and read run history to debug failed requests themselves. Everything is local-first — no account — with installers for Windows, macOS and Linux on GitHub Releases.
